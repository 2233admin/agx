# Operating ledger

The durable ledger is intentionally small. GitHub Issues and pull requests hold
the active contract and delivery evidence; this repository should not mirror
their complete history.

For each material operating decision, retain only:

- the decision and its bounded rationale;
- a stable link to the controlling Issue or pull request;
- the affected repository or capability;
- the date and responsible role;
- any review or expiry condition.

Do not commit command transcripts, provider inventory dumps, credentials,
machine paths, generated execution packages, or session-by-session journals.
