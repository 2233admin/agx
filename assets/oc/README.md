# AGXCLI OC kit

这套角色是 AGXCLI 的原创黑白 CRT 猫娘协调员：她表示安装、计划、验收与回执这一条工作链，而不是某个环境已经通过验收。所有成图均为二色 `#dee4e0` / `#2e382d` 的 CRT 画面，使用同一角色设定但按展示面重新构图，不靠裁切硬凑尺寸。公开资产不包含生成工具名称或签名。

| 文件 | 原始尺寸 | 建议落点 |
| --- | --- | --- |
| `agx-oc-github-banner-16x9.png` | 1672×941 | README 顶部横幅 |
| `agx-oc-avatar-square.png` | 1254×1254 | GitHub 头像、CLI 文档图标、Issue 模板头像 |
| `agx-oc-social-2x1.png` | 1774×887 | GitHub Settings → General → Social preview image |
| `agx-oc-overview.png` | 1448×1086 | README 主视觉、项目介绍 |
| `agx-oc-focus.png` | 1448×1086 | `plan` / `apply` 相关文档 |
| `agx-oc-queue.png` | 1448×1086 | `status` / `verify` / 回执相关文档 |

CLI 不渲染 PNG；运行 `agx mascot` 可显示同一角色的纯文本标识，保持 SSH、无 GUI 终端与日志输出可用。实际状态只以命令回执和端到端证据为准。
